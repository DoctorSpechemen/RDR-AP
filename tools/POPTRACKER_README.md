# RDR-AP PopTracker pack (0.5.0)

Put `RDR-AP_PopTracker.zip` in PopTracker's `packs` folder (PopTracker 0.18 or newer), open the pack and click **AP** to
connect with your slot name. Items and checks are then tracked automatically.

- **Map:** one pin per category in each territory (Story, Strangers, Gang Kills, Shops), one pin per gang hideout, and an
  **Anywhere** panel for checks that are not tied to a place: hat tricks, minigame wins, bounties and ranks (fame and honor titles).
- Checks that are not in your seed are hidden. Grey checks need more Dead Eye in logic (Landon Ricketts' missions and the
  story after them need level 3).
- Mexico and West Elizabeth checks only show as available once the story opens them: "Mexico Open" lights up when
  "We Shall Be Together in Paradise" is checked, "West Elizabeth Open" with "An Appointed Time" (the Story Progress row;
  click them yourself if you track by hand).
- Liar's Dice wins need the first Irish mission ("Liar's Dice Open", set by "Liars, Cheats and Other Proud Americans");
  Arm Wrestling wins need Mexico Open.
- Checks someone hinted for you are highlighted (needs a PopTracker version with highlight support).
- **Items:** the four Dead Eye levels, guns (blue), throwables (yellow) and outfits (red).

All icons and the map in this pack are original drawings. To use your own pictures instead, put PNG files with the same
names into PopTracker's user-override folder for this pack (`user-override/rdr1_ap/images/items/` in your PopTracker
documents folder); PopTracker uses them in place of the pack's own. File names: `images/items/<item name in lower case
with _>.png`, for example `cattleman_revolver.png`, `outfit__elegant_suit.png`, `deadeye_1.png`.
